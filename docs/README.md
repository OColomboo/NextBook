# Documentacao do projeto NextBook

Esta pasta contem uma leitura tecnica do codigo do app.

## Arquivos

- `01-visao-geral-arquitetura.md`: stack, estrutura, entrada da aplicacao, layout, componentes e observacoes gerais.
- `02-rotas-telas-fluxos.md`: telas, chaves de navegacao, estados locais e fluxos de cada funcionalidade.
- `03-firebase-banco-integracoes.md`: Firebase Auth, Realtime Database, Storage, servicos de dominio e APIs externas.

## Ordem sugerida de leitura

1. Comece pela visao geral para entender a arquitetura.
2. Leia rotas e fluxos para saber onde cada pagina esta e como o usuario percorre o app.
3. Feche com Firebase/banco para entender persistencia, conexoes e riscos de manutencao.
